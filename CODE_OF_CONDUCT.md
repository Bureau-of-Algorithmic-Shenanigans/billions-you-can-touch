# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Discuss figures and sources, not people. This project is about public money and
political decisions, so disagreement is expected: argue with evidence, keep it civil, and leave out personal attacks,
harassment and discriminatory language. Party-political campaigning does not belong in issues or pull requests.

**Reporting:** if someone behaves unacceptably, tell the maintainer privately through the
[private reporting form](https://github.com/Bureau-of-Algorithmic-Shenanigans/billions-you-can-touch/security/advisories/new)
(write "Code of conduct" in the title). Reports are handled confidentially. The maintainer may remove comments, close
issues or block participants who violate this code.
