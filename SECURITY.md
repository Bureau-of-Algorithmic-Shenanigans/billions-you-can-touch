# Security

This is a static website without a backend, accounts or stored personal data; settings stay in the visitor's browser.
Still, if you find a problem (for example a way to inject markup through the data files, or a vulnerable dependency),
please report it privately:
**[Report a vulnerability](https://github.com/Bureau-of-Algorithmic-Shenanigans/billions-you-can-touch/security/advisories/new)**.

Please don't open a public issue for it. You'll get an answer within a few days; fixes are deployed from `main`.
